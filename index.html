FULL STACK · LLM EVALUATION · REAL-TIME

A competitive game where the AI judge has to be fair.

Players trade roasts over five rounds against an AI opponent or a friend. The hard part is the scoring: LLM judges drift toward position, authorship and style, which makes any competitive result suspect.

HOW I SOLVED IT

  • Anonymized entries so the judge never sees who wrote what.
  • Randomized label order every round to remove positional bias.
  • Independent models for generation and for scoring.
  • Rubric scoring on wit, timing and topic relevance.
  • Deterministic outcome in code, so the model never decides the win/loss.
